# Kitty Configuration

This repository contains my personal configuration for the **Kitty** terminal emulator.

It is based closely on the default `kitty.conf`, with a few small customizations:

* A configured color theme
* A custom background image
* A couple uncommented mappings
* A couple of custom mappings

## Installation

Clone this repository into the Kitty configuration directory:

```bash
git clone https://github.com/<username>/<repo-name>.git ~/.config/kitty
```

Restart Kitty (or reload the configuration with shift+F5) to apply the settings.

## Configuration

The main configuration file is:

```
kitty.conf
```

Additional files (themes, images, etc.) are also included in this repository.

## Notes

This configuration stays intentionally close to the default Kitty setup, with only a few aesthetic changes.
